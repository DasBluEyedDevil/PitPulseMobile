# Plan 19-01: Touch Target Sweep

**Phase**: 19 — Touch Targets & Registration UX
**Requirements**: UIUX-15, UIUX-16, UIUX-17, UIUX-18, UIUX-19
**Depends on**: Nothing (independent of Phase 18)
**Estimated tasks**: 5

## Goal

Bring every interactive element identified in the UI audit to the 44px minimum touch target. All TextButtons ("Clear", "Restore Purchases", "See All", "Mark all read") get `minimumSize: Size(0, 44)` via their `style` parameter. The venue verified badge gets expanded padding and icon size for a 44px effective target. After this plan, no tappable element sits below the WCAG 2.5.8 / Apple HIG minimum.

## Context

**What exists:**
- `band_filters_sheet.dart` line ~236: "Clear" TextButton with default sizing (no explicit style)
- `venue_filters_sheet.dart` lines ~228, ~304: Two "Clear" TextButtons with default sizing
- `pro_feature_screen.dart` line ~191: "Restore Purchases" TextButton with default sizing
- `premium_paywall_sheet.dart` line ~158: "Restore Purchases" TextButton with default sizing
- `venue_detail_screen.dart` lines ~170-202: Verified badge Container with `padding: EdgeInsets.symmetric(horizontal: 8, vertical: 4)` and `Icon(size: 16)` — effective target is ~50×28px (icon 16 + padding 8 = too short vertically)
- `search_screen.dart` lines ~404-422: `_buildSeeAllButton()` helper method used 4 times, TextButton with no explicit minimumSize
- `venue_detail_screen.dart` line ~598: Standalone "See All" TextButton with no explicit style
- `notifications_screen.dart` lines ~32-45: "Mark all read" TextButton in AppBar actions with no explicit style

**What's wrong:**
- Flutter's default `TextButton` minimumSize is `Size(64, 36)` — the 36px height is below the 44px WCAG/HIG minimum
- Venue verified badge effective vertical target is ~28px (4px top + 16px icon + 4px bottom + ~4px text line height) — well below 44px
- All identified TextButtons rely on default 36px height

**Approach:**
- Use `TextButton.styleFrom(minimumSize: const Size(0, 44))` on each TextButton — this preserves existing text styling while only expanding the touch target height. Width stays `0` to keep horizontal sizing natural.
- For the venue badge, increase vertical padding and icon size to reach 44px effective target.

### Task 2: Expand venue verified badge touch target (UIUX-16)

**File**: `mobile/lib/src/features/venues/presentation/venue_detail_screen.dart`

**Lines ~170-202** — increase the verified badge padding and icon size for 44px effective target.

Current badge is `Tooltip → Container(padding: h8/v4) → Row(Icon(16) + Text(12))`.
Target: 44px effective height via increased vertical padding (14px each side) and icon bumped to 20px.

```dart
// Before:
else if (venue.isVerified)
  Tooltip(
    message: 'Verified venue',
    child: Container(
      padding: const EdgeInsets.symmetric(
        horizontal: 8,
        vertical: 4,
      ),
      decoration: BoxDecoration(
        color: AppTheme.info.withValues(alpha: 0.2),
        borderRadius: BorderRadius.circular(12),
      ),
      child: Row(
        mainAxisSize: MainAxisSize.min,
        children: const [
          Icon(
            Icons.verified,
            size: 16,
            color: AppTheme.info,
          ),
          SizedBox(width: 4),
          Text(
            'Verified',
            style: TextStyle(
              color: AppTheme.info,
              fontSize: 12,
              fontWeight: FontWeight.w600,
            ),
          ),
        ],
      ),
    ),
  ),

// After:
else if (venue.isVerified)
  Tooltip(
    message: 'Verified venue',
    child: Container(
      padding: const EdgeInsets.symmetric(
        horizontal: 10,
        vertical: 12,
      ),
      decoration: BoxDecoration(
        color: AppTheme.info.withValues(alpha: 0.2),
        borderRadius: BorderRadius.circular(16),
      ),
      child: Row(
        mainAxisSize: MainAxisSize.min,
        children: const [
          Icon(
            Icons.verified,
            size: 20,
            color: AppTheme.info,
          ),
          SizedBox(width: 4),
          Text(
            'Verified',
            style: TextStyle(
              color: AppTheme.info,
              fontSize: 12,
              fontWeight: FontWeight.w600,
            ),
          ),
        ],
      ),
    ),
  ),
```

Changes: `vertical: 4` → `vertical: 12` (adds 16px total vertical padding), `horizontal: 8` → `horizontal: 10`, `borderRadius: 12` → `16` (proportional), `Icon size: 16` → `20`. Effective height: 12 + 20 + 12 = 44px.

**Also check the "Claimed" badge** (lines ~137-169) for the same issue. Apply the same padding/icon change if its vertical padding is also `4`. Keep both badges visually consistent.
