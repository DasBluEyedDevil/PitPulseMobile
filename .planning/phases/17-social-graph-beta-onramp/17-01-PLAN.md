### Task 2: Create UserDiscoveryService with suggestion algorithm

**File**: `backend/src/services/UserDiscoveryService.ts` (NEW)

Create a lightweight suggestion service that recommends users to follow based on:
1. **Shared bands** — users who checked in to the same bands (highest weight)
2. **Shared venues** — users who checked in to the same venues
3. **Active users** — users with recent check-ins (recency boost)
4. **Not already following** — exclude existing follows
5. **Not blocked** — exclude blocked users

```typescript
export class UserDiscoveryService {
  async getSuggestions(userId: string, limit: number = 10): Promise<SuggestedUser[]>
}
```

SQL approach — single query with scoring:
```sql
WITH user_bands AS (
  SELECT DISTINCT el.band_id
  FROM checkins c
  JOIN event_lineup el ON el.event_id = c.event_id
  WHERE c.user_id = $1
),
user_venues AS (
  SELECT DISTINCT e.venue_id
  FROM checkins c
  JOIN events e ON c.event_id = e.id
  WHERE c.user_id = $1
),
candidates AS (
  SELECT u.id,
    COUNT(DISTINCT shared_band.band_id) AS shared_bands,
    COUNT(DISTINCT shared_venue.venue_id) AS shared_venues,
    MAX(c.created_at) AS last_checkin_at,
    u.total_checkins
  FROM users u
  JOIN checkins c ON c.user_id = u.id
  LEFT JOIN event_lineup shared_band ON shared_band.event_id = c.event_id
    AND shared_band.band_id IN (SELECT band_id FROM user_bands)
  LEFT JOIN (
    SELECT c2.user_id, e.venue_id
    FROM checkins c2
    JOIN events e ON c2.event_id = e.id
    WHERE e.venue_id IN (SELECT venue_id FROM user_venues)
  ) shared_venue ON shared_venue.user_id = u.id
  WHERE u.id != $1
    AND u.is_active = true
    AND NOT EXISTS (
      SELECT 1 FROM user_followers
      WHERE follower_id = $1 AND following_id = u.id
    )
    ${blockFilterSQL}
  GROUP BY u.id, u.total_checkins
  HAVING COUNT(c.id) > 0
)
SELECT u.id, u.username, u.first_name, u.last_name,
  u.profile_image_url, u.bio, u.total_checkins, u.is_verified,
  c.shared_bands, c.shared_venues
FROM candidates c
JOIN users u ON u.id = c.id
ORDER BY (c.shared_bands * 3 + c.shared_venues * 2 + LEAST(c.total_checkins, 20) * 0.1) DESC,
  c.last_checkin_at DESC NULLS LAST
LIMIT $2
```

Return type `SuggestedUser`:
```typescript
interface SuggestedUser {
  id: string;
  username: string;
  displayName: string;
  profileImageUrl: string | null;
  bio: string | null;
  totalCheckins: number;
  isVerified: boolean;
  sharedBands: number;
  sharedVenues: number;
  reason: string; // "5 bands in common", "Goes to the same venues"
}
```

Cache with Redis: `discover:suggestions:${userId}`, TTL 5 minutes.
