**File**: `mobile/lib/src/features/feed/presentation/providers/feed_providers.dart`

Add `GlobalFeedNotifier` following the same pattern as `FriendsFeedNotifier`:
```dart
@riverpod
class GlobalFeedNotifier extends _$GlobalFeedNotifier {
  String? _nextCursor;
  bool _hasMore = true;
  List<FeedItem> _items = [];

  @override
  Future<List<FeedItem>> build() async {
    _nextCursor = null;
    _hasMore = true;
    _items = [];
    return _fetchPage();
  }

  Future<List<FeedItem>> _fetchPage() async {
    final repo = ref.read(feedRepositoryProvider);
    final page = await repo.getGlobalFeed(cursor: _nextCursor);
    _nextCursor = page.nextCursor;
    _hasMore = page.hasMore;
    _items = [..._items, ...page.items];
    return _items;
  }

  Future<void> loadMore() async {
    if (!_hasMore) return;
    state = AsyncValue.data(await _fetchPage());
  }
}
```

Run `dart run build_runner build` after adding the new Riverpod annotation.

### Task 7: Modernize RevenueCat API (BETA-28)

**File**: `mobile/lib/src/features/subscription/presentation/subscription_service.dart`

Update `purchase()` to capture PurchaseResult (v9.0+ API):
```dart
/// Purchase result: null on cancellation/error, CustomerInfo on success
static Future<CustomerInfo?> purchase(Package package) async {
  try {
    final result = await Purchases.purchasePackage(package);
    return result.customerInfo;
  } on PlatformException catch (e) {
    final errorCode = PurchasesErrorHelper.getErrorCode(e);
    if (errorCode == PurchasesErrorCode.purchaseCancelledError) {
      return null; // User cancelled — not an error
    }
    rethrow; // Actual error — let caller handle
  }
}
```

Update `restorePurchases()` similarly — already returns CustomerInfo, but improve error handling:
```dart
static Future<CustomerInfo?> restorePurchases() async {
  try {
    return await Purchases.restorePurchases();
  } on PlatformException catch (e) {
    final errorCode = PurchasesErrorHelper.getErrorCode(e);
    logger.e('Restore error: $errorCode');
    return null;
  }
}
```

Update `isPremium()` to catch PlatformException specifically.

Replace the remaining `print()` statements with proper logging (if a logger is available) or remove them.
