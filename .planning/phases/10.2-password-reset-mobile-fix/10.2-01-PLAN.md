**Create reset_password_screen.dart:**

Create a new file following the ForgotPasswordScreen pattern (ConsumerStatefulWidget). The screen accepts a `token` parameter from the deep link.

Structure:
```dart
import 'package:flutter/material.dart';

class ResetPasswordScreen extends ConsumerStatefulWidget {
  final String token;
  const ResetPasswordScreen({super.key, required this.token});
  // ...
}
```

Three states:
1. **Error state (empty token):** If `token` is empty, show an error icon, "Invalid Reset Link" title, explanation text, and a "Back to Login" ElevatedButton that navigates to `/login`.

2. **Form state:** Two password fields (New Password, Confirm Password) with:
   - `_formKey` GlobalKey<FormState>
   - `_passwordController` and `_confirmPasswordController` TextEditingControllers
   - `_isLoading` bool state
   - `_obscurePassword` and `_obscureConfirm` bool states for visibility toggles
   - New Password field: validator uses `Validators.password`, has visibility toggle IconButton suffix
   - Confirm Password field: validator checks match against `_passwordController.text`, has visibility toggle
   - "Reset Password" ElevatedButton (disabled when `_isLoading`)
   - Loading spinner in button when `_isLoading` (same pattern as ForgotPasswordScreen)

3. **Success state:** Show success icon (Icons.check_circle_outline), "Password Reset Successfully" title, description text, and "Log in with New Password" ElevatedButton navigating to `/login`.

Submit handler `_handleSubmit()`:
- Validate form
- Set `_isLoading = true`
- Call `ref.read(dioClientProvider).post('/auth/reset-password', data: {'token': widget.token, 'newPassword': _passwordController.text})`
- On success: set `_resetComplete = true` state
- On error: show SnackBar with error message. If Failure type, use `e.message`. Special-case messages containing "expired" or "invalid" to show "This reset link has expired or is invalid. Please request a new one."
- Always set `_isLoading = false` in finally/catch

Styling: Match ForgotPasswordScreen exactly — same Scaffold backgroundColor (AppTheme.backgroundDark), AppBar style, icon sizes (64), spacing constants (AppTheme.spacing*), button styles (AppTheme.primary background, AppTheme.backgroundDark foreground, borderRadius 12, vertical padding 16, elevation 0).

Dispose both controllers in `dispose()`.

// Reset Password Route (Deep Link from email)
GoRoute(
  path: '/reset-password',
  name: 'reset-password',
  pageBuilder: (context, state) {
    final token = state.uri.queryParameters['token'] ?? '';
    return CustomTransitionPage(
      key: state.pageKey,
      child: ResetPasswordScreen(token: token),
      transitionsBuilder: (context, animation, secondaryAnimation, child) {
        const begin = Offset(1.0, 0.0);
        const end = Offset.zero;
        const curve = Curves.easeInOut;
        final tween = Tween(begin: begin, end: end).chain(
          CurveTween(curve: curve),
        );
        return SlideTransition(
          position: animation.drive(tween),
          child: child,
        );
      },
    );
  },
),
