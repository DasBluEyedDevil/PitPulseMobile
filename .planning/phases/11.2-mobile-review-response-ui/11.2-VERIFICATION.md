## Issues Found and Fixed

### Fixed: VERIFY-05 Reviewer Identity Degradation (P1 UX)

**Problem:** Backend `searchReviews` nests user data as `review.user = { username, firstName, profileImageUrl }` (ReviewService.ts:296-305). Mobile `Review.fromJson` reads flat `json['userName']` and `json['userProfileImageUrl']` — fields that don't exist at the top level. All reviewers showed as "Anonymous" with gradient initial avatar.

**Fix:** Added user object flattening in `ClaimRepository.getVenueReviews` (claim_repository.dart:111-117):
```dart
final user = json['user'] as Map<String, dynamic>?;
if (user != null) {
  json['userName'] = user['username'] as String? ?? user['firstName'] as String?;
  json['userProfileImageUrl'] = user['profileImageUrl'] as String?;
}
```

**Verification:** `dart analyze` clean, backend tests pass (56/56), TypeScript compiles clean.
