# Plan 21-02: Light Mode Color Audit + Icon Theme Definitions

**Phase**: 21 — Theme Cleanup & Light Mode Prep
**Requirements**: UIUX-32, UIUX-33
**Depends on**: Plan 21-01 (alias removal must complete first so audit references canonical names; `_NavItem` already uses `IconTheme.of(context).size`)

## Goal

Audit every light theme color pair for WCAG AA compliance and document the results, then add explicit `IconThemeData` size values to both dark and light themes so `_NavItem` (already updated in Plan 21-01 to use `IconTheme.of(context).size`) and other theme-aware widgets can inherit icon sizes.

## Context

**What exists:**

- `AppTheme.lightTheme` defined at `app_theme.dart:528-744` — uses hardcoded `Color()` values
- Dark theme has `iconTheme: IconThemeData(color: textPrimary)` at line 460-462 — no `size` specified
- Light theme has no top-level `iconTheme` defined (only `appBarTheme.iconTheme` exists at line 555 for app bar icons)
- `_NavItem` already updated by Plan 21-01 to use `IconTheme.of(context).size ?? 24` — but current theme provides no `size`, so fallback to 24 is always used
- Light theme primary `#2E7D32` (dark forest green) is borderline for AA on white — ~4.52:1 ratio
- Light theme scaffold background is `#F0F2F5`, card color is `Colors.white`

**What's wrong:**

- No documented audit of light theme color pairs exists — can't enable light mode without knowing which pairs fail
- `IconThemeData` in both themes lacks explicit `size` — theme-responsive sizing is incomplete
- Light theme may have undiscovered contrast failures (e.g., `electricBlue`/cyan on white is ~1.3:1)

## Tasks

### Task 1: Audit light theme color pairs for WCAG AA (UIUX-32)

Compute contrast ratios for every foreground/background color combination used in the light theme using the WCAG 2.1 relative luminance formula:

For each 8-bit RGB channel, normalize to [0-1] then linearize:

- If `C_srgb <= 0.03928`: `C' = C_srgb / 12.92`
- Else: `C' = ((C_srgb + 0.055) / 1.055) ^ 2.4`

Then:

- Relative luminance: `L = 0.2126 * R' + 0.7152 * G' + 0.0722 * B'`
- Contrast ratio: `(L_lighter + 0.05) / (L_darker + 0.05)`
- AA normal text (< 18px): >= 4.5:1
- AA large text (>= 18px bold or >= 24px): >= 3:1
- AAA normal text: >= 7:1

### Task 2: Add icon size to IconThemeData in both themes (UIUX-33)

**File**: `mobile/lib/src/core/theme/app_theme.dart`

**Step 2a**: In dark theme `iconTheme` (line 460-462), add explicit size:

```dart
// Before:
iconTheme: const IconThemeData(
  color: textPrimary,
),

// After:
iconTheme: const IconThemeData(
  color: textPrimary,
  size: 24,
),
```

**Step 2b**: Add top-level `iconTheme` to light theme (currently missing — only `appBarTheme.iconTheme` exists):

```dart
// Add after the existing appBarTheme block in lightTheme:
iconTheme: const IconThemeData(
  color: Color(0xFF0D0F11),
  size: 24,
),
```

Now `IconTheme.of(context).size` in `_NavItem` (from Plan 21-01) resolves to `24` from the theme instead of falling back to the hardcoded `?? 24`. If a future theme change adjusts the size, all icon-theme-aware widgets respond automatically.
