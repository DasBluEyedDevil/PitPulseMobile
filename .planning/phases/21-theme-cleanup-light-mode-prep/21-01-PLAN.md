# Plan 21-01: Color Alias Removal + Nav Fixes + Notification Badge

**Phase**: 21 — Theme Cleanup & Light Mode Prep
**Requirements**: UIUX-28, UIUX-29, UIUX-30, UIUX-31
**Depends on**: Phase 18 (contrast values finalized)
**Estimated tasks**: 4

## Goal

Eliminate the confusing `electricPurple`, `liveGreen`, and `neonPink` color aliases, rename the bottom nav "Alerts" tab to "Notifications" per Jakob's Law, and add an unread notification count badge to the Notifications nav item.

## Context

**What exists:**
- `AppTheme.electricPurple = voltLime` (line 68), `electricPurpleLight = voltLimeLight` (line 69), `electricPurpleDark = voltLimeDark` (line 70) — legacy aliases in `app_theme.dart`
- `AppTheme.liveGreen = voltLime` (line 72) — legacy alias in `app_theme.dart`
- `AppTheme.neonPink = hotOrange` (line 71) — legacy alias in `app_theme.dart`
- 157 `electricPurple` references across 18 files (3 are definitions in `app_theme.dart`; 154 are usage refs across 17 files)
- 24 `liveGreen` references across 12 files (1 definition + 23 usage refs)
- 38 `neonPink` references across 10 files (1 definition + 37 usage refs)
- `electricPurpleLight` and `electricPurpleDark` have zero usage outside their definitions — only need deletion
- Bottom nav `_NavItem` at `scaffold_with_nav_bar.dart:116` has `label: 'Alerts'` — should be "Notifications"
- `unreadNotificationCountProvider` already exists in `notification_providers.dart:25` — returns `Future<int>` via `GET /notifications/unread-count`
- `ScaffoldWithNavBar` is a plain `StatelessWidget` — needs Riverpod access for badge count

**What's wrong:**
- `electricPurple` name is misleading — the color is actually `voltLime` (`#D2FF00`, acid green), not purple
- `liveGreen` is redundant — identical to `voltLime`, creates confusion about which to use
- `neonPink` is misleading — the color is `hotOrange` (`#FF3D00`), not pink
- "Alerts" violates Jakob's Law — every major platform uses "Notifications"
- Feed tabs show live dots/badges but Notifications tab has no unread indicator

### Task 3: Add notification badge to _NavItem (UIUX-31)

**File**: `mobile/lib/src/shared/widgets/scaffold_with_nav_bar.dart`

**Step 3a**: Add Riverpod import and notification provider import:
```dart
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../../features/notifications/presentation/providers/notification_providers.dart';
```

**Step 3b**: Add optional `badgeCount` parameter to `_NavItem`:
```dart
class _NavItem extends StatelessWidget {
  const _NavItem({
    required this.icon,
    required this.label,
    required this.isSelected,
    required this.onTap,
    this.badgeCount = 0,
  });

  final IconData icon;
  final String label;
  final bool isSelected;
  final VoidCallback onTap;
  final int badgeCount;
```

**Step 3c**: Wrap the `Icon` in a `Badge` widget when `badgeCount > 0`. Use `IconTheme.of(context).size ?? 24` instead of hardcoded `size: 24` (prep for UIUX-33):
```dart
// Replace the Icon widget with:
Builder(
  builder: (context) {
    final iconSize = IconTheme.of(context).size ?? 24;
    final iconWidget = Icon(
      icon,
      size: iconSize,
      color: isSelected
          ? AppTheme.voltLime
          : AppTheme.textTertiary,
    );
    return badgeCount > 0
        ? Badge(
            label: Text(
              badgeCount > 99 ? '99+' : '$badgeCount',
              style: const TextStyle(
                fontSize: 10,
                fontWeight: FontWeight.bold,
                color: Colors.white,
              ),
            ),
            backgroundColor: AppTheme.hotOrange,
            child: iconWidget,
          )
        : iconWidget;
  },
),
```

Note: This already uses `IconTheme.of(context).size` for icon sizing, satisfying UIUX-33's `_NavItem` requirement. Plan 21-02 only needs to add the `IconThemeData` size values to the theme definitions.

**Step 3d**: Wrap the Notifications `_NavItem` in a `Consumer` widget to read unread count:
```dart
// Replace the Notifications _NavItem (lines 113-119) with:
Consumer(
  builder: (context, ref, child) {
    final unreadCount = ref.watch(unreadNotificationCountProvider);
    return _NavItem(
      icon: Icons.notifications,
      label: 'Notifications',
      isSelected: selectedIndex == 4,
      onTap: () => onTap(4),
      badgeCount: unreadCount.valueOrNull ?? 0,
    );
  },
),
```

`Consumer` widget avoids converting the entire `_CustomBottomNavBar` to a `ConsumerWidget` — minimal change surface.
