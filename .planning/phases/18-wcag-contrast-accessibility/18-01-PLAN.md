# Plan 18-01: WCAG Contrast & Typography Fixes

**Phase**: 18 — WCAG Contrast & Accessibility
**Requirements**: UIUX-01, UIUX-02, UIUX-03, UIUX-04, UIUX-05
**Depends on**: Nothing (first phase of v3.0)
**Estimated tasks**: 6

## Goal

Fix all WCAG AA contrast failures across the app. Every instance of `textTertiary` at small font sizes (which yields ~3.8:1 ratio on `backgroundDark`) gets bumped to `textSecondary` at 13–14px (yielding ~5.4:1). Social icon backgrounds get higher alpha for sufficient contrast. Search hint text gets explicit font sizing. No font size below 13px on any user-visible text element.

## Context

**What exists:**

- `AppTheme.textTertiary = Color(0xFF6E7681)` — ~3.8:1 on backgroundDark (fails AA for <18px text)
- `AppTheme.textSecondary = Color(0xFF8B949E)` — ~5.4:1 on backgroundDark (passes AA for all sizes)
- `AppTheme.backgroundDark = Color(0xFF0D0F11)`, `cardDark = Color(0xFF1C2128)`
- `_SocialIcon` in band_detail_screen.dart uses `color.withValues(alpha: 0.15)` — ~2.5:1 fails AA
- Six `textTertiary` + `fontSize: 12` instances in venue_detail_screen.dart (lines 378, 730, 905, 920, 1133, 1377)
- Two `textTertiary` + `fontSize: 11` instances in venue_detail_screen.dart (lines 538, 1202)
- One `textTertiary` + `fontSize: 11` instance in band_detail_screen.dart (line 464)
- One `textTertiary` + `fontSize: 12` instance in notifications_screen.dart (line 325)
- Two `fontSize: 12` overrides on footer links in pro_feature_screen.dart (lines 213, 220)
- search_screen.dart hintStyle uses `textSecondary` without explicit fontSize (line 59)

**What's wrong:**

- `textTertiary` at 12px on dark background = ~3.8:1, fails WCAG AA minimum of 4.5:1 for normal text
- `textTertiary` at 11px is even worse — same ~3.8:1 ratio at an even smaller size
- Social icon 0.15 alpha background with icon foreground = ~2.5:1, fails AA
- Pro footer links at 12px are below the 13px minimum readability threshold
- Search hint text has no explicit fontSize, could drift from input text sizing

## Tasks

### Task 1: Increase social icon background alpha (UIUX-01)

**File**: `mobile/lib/src/features/bands/presentation/band_detail_screen.dart`

In the `_SocialIcon` widget, change the background alpha from `0.15` to `0.3` to achieve ~4.5:1+ contrast ratio.

**Line ~915** — change:

```dart
color: color.withValues(alpha:0.15),
```

to:

```dart
color: color.withValues(alpha: 0.3),
```

This raises the background luminance enough that the icon foreground color meets WCAG AA against the background.

### Task 3: Fix notifications timestamp contrast (UIUX-03)

**File**: `mobile/lib/src/features/notifications/presentation/notifications_screen.dart`

### Task 5: Add explicit fontSize to search hint (UIUX-05)

**File**: `mobile/lib/src/features/search/presentation/search_screen.dart`

**Line ~59** — add explicit `fontSize` to the hintStyle to match the input text sizing:

```dart
// Before:
hintStyle: TextStyle(color: AppTheme.textSecondary),
// After:
hintStyle: TextStyle(color: AppTheme.textSecondary, fontSize: 18),
```

The input text already has `fontSize: 18` (line ~61). Making the hint match ensures consistent sizing and keeps the textSecondary contrast well above AA threshold at this size (5.4:1, large text rules apply at 18px).
