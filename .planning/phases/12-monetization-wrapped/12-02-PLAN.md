**Method: `getWrappedStats(userId: string, year: number): Promise<WrappedStats>`**
Computes basic Wrapped stats (free tier). All queries add year filter: `AND EXTRACT(YEAR FROM c.created_at) = $2`.

Run in parallel (Promise.all):
1. **Basic counts** (mirror StatsService.getBasicStats but add year filter):
   - total_shows: COUNT(DISTINCT c.id) from checkins where user_id=$1, is_hidden NOT TRUE, EXTRACT(YEAR)=$2
   - unique_bands: COUNT(DISTINCT el.band_id) from checkins JOIN event_lineup, same filters
   - unique_venues: COUNT(DISTINCT c.venue_id), same filters

2. **Top genre** (mirror StatsService.getGenreBreakdown but LIMIT 1):
   - JOIN checkins → event_lineup → bands, GROUP BY b.genre, ORDER BY count DESC LIMIT 1
   - Calculate percentage from total genre-matched check-ins for the year

3. **Home venue** (top venue by visit count):
   ```sql
   SELECT v.id, v.name, COUNT(DISTINCT c.id)::int as visits
   FROM checkins c JOIN venues v ON c.venue_id = v.id
   WHERE c.user_id = $1 AND c.is_hidden IS NOT TRUE
     AND EXTRACT(YEAR FROM c.created_at) = $2
   GROUP BY v.id, v.name
   ORDER BY visits DESC LIMIT 1
   ```

4. **Top artist** (most times seen):
   ```sql
   SELECT b.id, b.name, COUNT(DISTINCT c.id)::int as times_seen
   FROM checkins c
   JOIN event_lineup el ON c.event_id = el.event_id
   JOIN bands b ON el.band_id = b.id
   WHERE c.user_id = $1 AND c.is_hidden IS NOT TRUE
     AND EXTRACT(YEAR FROM c.created_at) = $2
   GROUP BY b.id, b.name
   ORDER BY times_seen DESC LIMIT 1
   ```

Return WrappedStats object with `meetsThreshold: totalShows >= 3`.

**Method: `getWrappedDetailStats(userId: string, year: number): Promise<WrappedDetailStats>`**
Calls `getWrappedStats` first, then computes premium-only stats in parallel:

1. **Monthly breakdown** (12 months):
   ```sql
   SELECT EXTRACT(MONTH FROM c.created_at)::int as month, COUNT(DISTINCT c.id)::int as show_count
   FROM checkins c WHERE c.user_id = $1 AND c.is_hidden IS NOT TRUE
     AND EXTRACT(YEAR FROM c.created_at) = $2
   GROUP BY month ORDER BY month
   ```
   Fill in zero-count months (1-12) for the full array.

2. **Genre evolution** (genre per month):
   ```sql
   SELECT EXTRACT(MONTH FROM c.created_at)::int as month, b.genre, COUNT(DISTINCT c.id)::int as count
   FROM checkins c JOIN event_lineup el ON c.event_id = el.event_id JOIN bands b ON el.band_id = b.id
   WHERE c.user_id = $1 AND b.genre IS NOT NULL AND c.is_hidden IS NOT TRUE
     AND EXTRACT(YEAR FROM c.created_at) = $2
   GROUP BY month, b.genre ORDER BY month, count DESC
   ```

3. **Friend overlap** (friends who attended same events):
   ```sql
   SELECT f_user.id as friend_id, f_user.username as friend_username,
          f_user.profile_image_url as friend_profile_image_url,
          COUNT(DISTINCT c2.event_id)::int as shared_shows
   FROM checkins c1
   JOIN checkins c2 ON c1.event_id = c2.event_id AND c1.user_id != c2.user_id
   JOIN user_followers uf ON uf.follower_id = $1 AND uf.following_id = c2.user_id
   JOIN users f_user ON f_user.id = c2.user_id
   WHERE c1.user_id = $1 AND c1.is_hidden IS NOT TRUE AND c2.is_hidden IS NOT TRUE
     AND EXTRACT(YEAR FROM c1.created_at) = $2
     AND EXTRACT(YEAR FROM c2.created_at) = $2
   GROUP BY f_user.id, f_user.username, f_user.profile_image_url
   ORDER BY shared_shows DESC LIMIT 10
   ```

4. **Top rated sets** (highest band ratings):
   ```sql
   SELECT b.name as band_name, b.id as band_id, v.name as venue_name,
          e.event_date::text as event_date, cbr.rating
   FROM checkin_band_ratings cbr
   JOIN checkins c ON cbr.checkin_id = c.id
   JOIN bands b ON cbr.band_id = b.id
   JOIN events e ON c.event_id = e.id
   JOIN venues v ON c.venue_id = v.id
   WHERE c.user_id = $1 AND c.is_hidden IS NOT TRUE
     AND EXTRACT(YEAR FROM c.created_at) = $2
   ORDER BY cbr.rating DESC, e.event_date DESC LIMIT 10
   ```

**Create WrappedController.ts:**

```typescript
import { Request, Response } from 'express';
import { WrappedService } from '../services/WrappedService';

export class WrappedController {
  private wrappedService = new WrappedService();

  /**
   * GET /api/wrapped/:year — Basic Wrapped stats (free tier)
   */
  getWrapped = async (req: Request, res: Response): Promise<void> => {
    try {
      const userId = req.user!.id;
      const year = parseInt(req.params.year, 10);

      if (isNaN(year) || year < 2020 || year > new Date().getFullYear()) {
        res.status(400).json({ success: false, error: 'Invalid year' });
        return;
      }

      const stats = await this.wrappedService.getWrappedStats(userId, year);
      res.json({ success: true, data: stats });
    } catch (error) {
      console.error('WrappedController.getWrapped error:', error);
      res.status(500).json({ success: false, error: 'Failed to generate Wrapped stats' });
    }
  };

  /**
   * GET /api/wrapped/:year/detail — Premium detail stats (requires premium)
   */
  getWrappedDetail = async (req: Request, res: Response): Promise<void> => {
    try {
      const userId = req.user!.id;
      const year = parseInt(req.params.year, 10);

      if (isNaN(year) || year < 2020 || year > new Date().getFullYear()) {
        res.status(400).json({ success: false, error: 'Invalid year' });
        return;
      }

      const stats = await this.wrappedService.getWrappedDetailStats(userId, year);
      res.json({ success: true, data: stats });
    } catch (error) {
      console.error('WrappedController.getWrappedDetail error:', error);
      res.status(500).json({ success: false, error: 'Failed to generate Wrapped detail stats' });
    }
  };
}
```
