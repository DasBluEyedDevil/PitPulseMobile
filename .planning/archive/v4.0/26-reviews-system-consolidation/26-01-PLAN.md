  <files>backend/src/services/VenueService.ts</files>
  <action>
Read `backend/src/services/VenueService.ts` and find the `updateVenueRating()` method.

Current implementation reads from `reviews`:
```sql
SELECT COALESCE(AVG(rating::numeric), 0) FROM reviews WHERE venue_id = $1
SELECT COUNT(*) FROM reviews WHERE venue_id = $1
```

Rewrite to compute from `checkins.venue_rating`:
```sql
SELECT COALESCE(AVG(venue_rating::numeric), 0) FROM checkins WHERE venue_id = $1 AND venue_rating IS NOT NULL
SELECT COUNT(*) FROM checkins WHERE venue_id = $1 AND venue_rating IS NOT NULL
```

This is correct because:
- `checkins.venue_rating` stores the venue experience rating from event check-ins
- Only count check-ins that actually have a venue rating (not all check-ins)

<task type="auto">
  <name>Task 2: Rewrite BandService.updateBandRating()</name>
  <files>backend/src/services/BandService.ts</files>
  <action>
Read `backend/src/services/BandService.ts` and find the `updateBandRating()` method.

Current implementation reads from `reviews`:
```sql
SELECT COALESCE(AVG(rating::numeric), 0) FROM reviews WHERE band_id = $1
SELECT COUNT(*) FROM reviews WHERE band_id = $1
```

Rewrite to compute from `checkin_band_ratings`:
```sql
SELECT COALESCE(AVG(rating::numeric), 0) FROM checkin_band_ratings WHERE band_id = $1
SELECT COUNT(*) FROM checkin_band_ratings WHERE band_id = $1
```

This is correct because:
- `checkin_band_ratings` stores per-band performance ratings from event check-ins
- Every row represents a specific band rating from a specific check-in
